Detailed Description

CRC computation engine: CRC-8/SAE-J1850, CRC-16/CCITT, CRC-32/ISO.

Design decisions:

  • Table-driven implementation for speed (256-entry lookup tables).
  • Tables are computed once at init (demonstrates recursion for table fill), or optionally compile-time constant via ECUS_CRC_STATIC_TABLES.
  • All functions are pure (no side-effects, same input → same output).
  • Streaming API (Init / Update / Finalize) supports large payloads processed in chunks — common in embedded bootloader and UDS scenarios.

Automotive relevance: CRC-8 : SAE J1850 used in OBD-II / CAN frame validation. CRC-16 : ISO 15765-2 (ISO-TP) header integrity. CRC-32 : ECU firmware image integrity verification.
