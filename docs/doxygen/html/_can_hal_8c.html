Detailed Description

Virtual CAN HAL implementation — POSIX thread simulates CAN ISR.

C concepts demonstrated: POSIX threads (pthread_create, pthread_join, pthread_mutex), volatile flag for clean thread shutdown, function pointer callback dispatch, struct for module state encapsulation, atomic counters for stats, ring buffer usage (push/pop), nanosleep() for ISR timing simulation.
