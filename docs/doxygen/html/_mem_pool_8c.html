Detailed Description

Fixed-size block memory pool implementation.

C concepts demonstrated: void* / pointer casting, pointer arithmetic (uint8_t* walking), struct overlay (FreeNode on raw buffer bytes), alignment verification (ECUS_ALIGN_UP macro), boundary check (block-in-range validation), memset for zero-initialisation of allocated blocks, optional POSIX mutex via conditional compilation.
