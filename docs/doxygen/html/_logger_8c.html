Detailed Description

Implementation of the ECUS variadic logging framework.

C concepts demonstrated: va_list / va_start / va_end (variadic functions), POSIX pthread_mutex (thread safety), FILE* I/O, fprintf, vfprintf, static module state, const char* arrays, conditional compilation (#if / #ifdef), function pointers (internal dispatch), time()/localtime() for timestamps, safe string handling (snprintf, never strcpy).
