Detailed Description

Master platform abstraction header.

Provides fixed-width integer types, compiler-portability macros, MISRA-C helper annotations, boolean type, and project-wide compile-time constants. Every translation unit in ECUS includes this header (directly or transitively).

Note
Target: hosted POSIX environment (Linux / macOS). Compiler: GCC >= 9 or Clang >= 10, C11 mode.

ECUS Project
