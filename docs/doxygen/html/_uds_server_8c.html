Detailed Description

UDS server implementation — top-level integration.

C concepts demonstrated: Callback registration and invocation (ISO-TP PDU callback), struct member access and update, string handling (strncpy safe pattern), timer management (uint32_t ms counters), linear search on struct array (DID / DTC lookup), session/security state management.
