Detailed Description

Virtual CAN Hardware Abstraction Layer (HAL).

On real hardware (STM32, NXP S32K) this module would wrap FDCAN/msCAN peripheral registers. In the ECUS simulator it provides:

  • A virtual CAN bus backed by two in-process RingBuffers (Rx, Tx).
  • A background POSIX thread ("CAN ISR simulator") that drains Tx frames and echoes them back into the Rx buffer (loopback mode) or routes them to a registered tester node.
  • Callback-based Rx notification (mirrors a real interrupt handler).
  • Tx filter: only frames matching the registered ECU CAN ID are accepted.

C concepts demonstrated: function pointer callbacks, opaque HAL state, POSIX threads, volatile flag for thread control, struct for HAL configuration.
