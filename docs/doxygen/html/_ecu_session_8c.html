Detailed Description

ECU bootstrap implementation — wires all subsystems together.

C concepts demonstrated: Module composition root pattern, POSIX thread for periodic tick, callback wiring (CanHal Rx → UdsServer), static singleton instance, designated initializers for struct literals, string literals as data.
