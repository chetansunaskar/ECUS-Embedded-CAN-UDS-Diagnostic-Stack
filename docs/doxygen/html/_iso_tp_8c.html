Detailed Description

ISO 15765-2 transport protocol — Rx/Tx state machines.

C concepts demonstrated: Multi-state machine (enum + switch/case), bit manipulation (PCI nibble extraction: frame->data[0] >> 4), struct-based context (no global state — supports multiple channels), function pointer callback invocation, memcpy for safe buffer operations, bounds checking before every buffer write, pointer-to-const for read-only data parameters.
