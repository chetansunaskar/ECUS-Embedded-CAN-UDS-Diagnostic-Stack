Detailed Description

Interactive command-line shell for ECUS simulator control.

Implements a mini shell that lets the user inject UDS requests, inspect server state, and trigger fault scenarios — all without needing a real CAN bus.

Demonstrates: command dispatch table, argv/argc pattern, string parsing, sscanf for hex input, function pointer command handlers.
